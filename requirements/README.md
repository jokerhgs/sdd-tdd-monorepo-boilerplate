# Requirements

Human-written, short. One file per domain: `requirements/<domain>.md`.

Format: `_template.md` (same directory):

```markdown
# <Domain> requirements

Goal: one sentence on why this exists.

- Plain-language requirement
- Another requirement

Out of scope:

- Things the agent must not build
```

See `AGENTS.md` for the full workflow (requirements → spec → server → client → verify).
